FOR THE BUILDERS

Alur kerjamu.
API kami.

Hubungkan VELOX dengan project-mu. JSON sederhana, endpoint jelas, tanpa API key untuk penggunaan wajar.

Rate limit per IP tetap berlaku.
# Kenali link, dapatkan formatnya.
curl -X POST /api/resolve \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://youtu.be/VIDEO_ID"}'

Respons: title, thumbnail, items[].formats[]

# Pakai URL dari items[].formats[].url.
GET /api/dl?t=direct&u=<cdn-url>&n=<file>

# Konversi audio lewat engine.
GET /api/dl?t=engine&u=<page-url>&a=mp3

Parameter URL harus di-encode. Paling praktis: gunakan URL dari respons resolve.

# Periksa kesiapan engine.
curl /api/health

# status, engine, cache, queue, limits

Status dapat berupa ok atau degraded.

A LITTLE CLARITY

Masih penasaran?

Hal-hal kecil yang perlu kamu tahu sebelum menyimpan inspirasi.

✳
Gratis, beneran?+

Ya, antarmuka ini tidak memerlukan akun atau pembayaran. Server membatasi jumlah permintaan per IP agar tetap responsif. Jika terkena batas, tunggu sebentar sebelum mencoba lagi.

Apakah semua video bisa tanpa watermark?+

Tidak selalu. Hasil mengikuti berkas yang tersedia dari sumber dan resolver. Jika tersedia versi tanpa watermark, label format akan menunjukkannya. Watermark yang sudah menyatu di video tidak otomatis dihapus.

Kenapa link-ku belum bisa diproses?+

Konten mungkin privat, sudah dihapus, dibatasi wilayah, atau sumber sedang memblokir akses otomatis. Pastikan link publik masih bisa dibuka. Sebagian format juga memerlukan yt-dlp dan ffmpeg yang aktif di server.

Apa yang disimpan oleh VELOX?+

Riwayat link tersimpan di localStorage browser ini, bukan dalam akun. Link dikirim ke server dan layanan sumber untuk diproses; hasil resolve di-cache sementara. Penggabungan dan konversi media dapat memakai file sementara di server. Jangan kirim link yang berisi informasi sensitif.

Bisa simpan playlist dan banyak foto?+

Jika didukung sumber, playlist menampilkan tiap item (batas default 30), dan carousel menampilkan pilihan unduh fotonya. Setiap berkas diunduh satu per satu, bukan sebagai ZIP otomatis.

Boleh dipakai untuk konten apa saja?+

Gunakan untuk konten milikmu, berlisensi sesuai penggunaanmu, atau yang telah mendapat izin pemiliknya. Bisa diakses publik bukan berarti bebas digunakan. Hormati hak cipta serta ketentuan layanan setiap platform.
